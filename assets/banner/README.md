# Profile Banner

This folder contains the visual assets for the GitHub Profile README.

## 🖼️ Banner Details
* **File**: `banner.png` (Dimensions: 1024x1024, styled in a dark-mode first glassmorphic cyber-security grid layout).
* **Theme**: Cyber Green and Teal Network Nodes with Shield outlines, representing AI agent security, zero-trust gateways, and protocol engineering.

## 🛠️ Usage in README
In the `README.md`, this banner can be embedded directly from this repository or combined dynamically with services like `capsule-render`.

```markdown
<p align="center">
  <img src="assets/banner/banner.png" alt="Akul Bansal - Cyber Security Node Grid" width="100%" />
</p>
```

Alternatively, you can use the dynamic `capsule-render` URL if you prefer a wave-based SVG effect instead of a static image. Both are supported in the provided templates.
